# EV Charger KR (한국 전기차 충전소)

Home Assistant에서 **공공데이터포털(한국환경공단_전기자동차 충전소 정보)** Open API를 이용해 사용자가 등록한 국내 전기차 충전소의 **충전 가능 대수** 및 충전기 상태를 조회하는 HACS / Marketplace 호환 커스텀 통합 구성요소입니다.

환경부(기후부) 공공 충전기뿐만 아니라 무공해차 통합누리집에 연계된 민간 충전사업자(채비, GS차지비, 이지차저, 한국전력 등) 충전소 상태를 통합 조회할 수 있으며, **구역 진입 시 모바일 알림을 보내는 자동화 블루프린트**도 함께 제공합니다.

---

## 주요 기능

- **지역·키워드 검색 및 체크박스 다중 등록 (`Config Flow`)**:
  - 충전소 ID(`statId`)를 몰라도 시/도와 충전소명(또는 주소) 키워드로 검색한 뒤 **체크박스로 여러 충전소를 한 번에 등록**할 수 있습니다.
  - 등록 후 **구성(Configure)** 메뉴에서 다른 시/도의 충전소를 추가 검색하거나 기존 충전소를 관리·삭제할 수 있습니다.
- **충전소별 4종 센서 제공**:
  - **충전 가능 대수** (`available_chargers`, 단위: `대`) — 상태가 `충전대기(2)`인 충전기 수
  - **충전 중 대수** (`charging_chargers`, 단위: `대`) — 상태가 `충전중(3)`인 충전기 수
  - **전체 충전기 수** (`total_chargers`, 단위: `대`)
  - **사용 불가 대수** (`unavailable_chargers`, 단위: `대`) — 통신이상·운영중지·점검중·예약중 등
- **API 일일 잔여 한도 센서 제공** (`api_rate_limit_remaining`, 단위: `건`):
  - 응답 헤더(`X-RateLimit-Remaining`, `X-RateLimit-Limit`)를 기반으로 추가 API 호출 없이 일일 잔여 한도와 사용률을 표시합니다.
- **상세 속성(`extra_state_attributes`) 제공** (`충전 가능 대수` 센서):
  - `stat_id`, `station_name`, `address`, `operator` (충전기 운영사)
  - `fast_available_chargers` (급속 충전 가능 대수), `slow_available_chargers` (완속 충전 가능 대수)
  - `chargers` (충전기별 `charger_id`, `status`, `status_code`, `type`, `output_kw`, `updated_at`)
- **조회 주기 자동 조절 (`Options Flow`)**:
  - 등록된 전체 충전소 수와 일일 API 한도(기본 1,000건의 85% 이내)에 맞춰 갱신 주기를 자동 계산·적용합니다. (수동 1~60분 고정 주기로 전환 가능)
- **구역 진입 알림 블루프린트 제공**:
  - 지정한 구역(최대 3개)에 진입하면 각 구역에 매핑된 충전소의 가용 대수를 모바일 앱 알림으로 전송합니다.

## 1단계: 공공데이터포털 API 키 발급

1. [공공데이터포털(data.go.kr)](https://www.data.go.kr/) 로그인
2. [한국환경공단_전기자동차 충전소 정보](https://www.data.go.kr/data/15076352/openapi.do) 페이지로 이동 후 **활용신청** 클릭
   - 개발단계/운영단계 모두 **자동승인**이며, 기본 일일 트래픽은 **1,000건**입니다.
   - 활용 목적 입력 시 예: `Home Assistant 개인 스마트홈에서 등록한 전기차 충전소의 실시간 충전 가능 대수 및 상태 조회용 연동`
3. 승인 후 **마이페이지 → Open API → 인증키 발급현황**에서 **일반 인증키(Encoding 또는 Decoding)**를 복사해 둡니다.
   - 이 통합 구성요소는 `Encoding` / `Decoding` 키 모두 자동으로 정규화하여 처리합니다.
   - 참고: 신규 발급 직후에는 공공데이터포털 게이트웨이 반영까지 **수 분~최대 1시간** 정도 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 발생할 수 있습니다.

## 2단계: Home Assistant에 설치

### 방법 1: HACS / Marketplace 사용자 지정 저장소 (권장)

1. Home Assistant에서 **HACS**(또는 **설정 → Marketplace**) → **통합 구성요소**로 이동합니다.
2. 우측 상단 메뉴(`⋮`) → **사용자 지정 저장소(Custom repositories)**를 선택합니다.
3. 저장소 URL에 아래 주소를 입력하고, 카테고리는 **Integration**을 선택해 추가합니다.
   ```text
   https://github.com/helico717/ha-ev-charger-kr
   ```
4. 목록에서 **EV Charger KR (한국 전기차 충전소)**를 찾아 **다운로드**합니다.
5. Home Assistant를 **재시작**합니다.

### 방법 2: 수동 설치

1. 이 저장소의 `custom_components/ev_charger_kr` 폴더를 Home Assistant 설정 디렉터리의 `/config/custom_components/ev_charger_kr` 경로로 복사합니다.
2. Home Assistant를 **재시작**합니다.

## 3단계: 통합 구성요소 등록 및 관리

1. Home Assistant에서 **설정 → 기기 및 서비스 → 통합 구성요소 추가**를 클릭합니다.
2. **EV Charger KR**을 검색해 선택합니다.
3. 발급받은 **공공데이터포털 API 인증키**를 입력합니다. *(이미 등록된 항목이 있다면 기존 API 키가 자동으로 채워집니다.)*
4. **시/도**를 선택하고 **충전소 이름 또는 주소 키워드**(예: `서울시청`, `판교역`)를 입력한 뒤 **확인**을 누르면, 검색된 충전소 목록(충전소명 · 운영사 · 충전기 수 · 주소)에서 **체크박스로 여러 충전소를 한 번에 선택**해 등록할 수 있습니다.
   - `statId`를 이미 알고 있다면 키워드 대신 **충전소 ID 직접 입력**란에 바로 입력해도 됩니다.
5. 다른 시/도의 충전소를 추가하거나 기존 충전소를 삭제하려면 항목의 **구성(Configure)** 메뉴에서 **충전소 추가 검색** / **등록된 충전소 관리**를 이용할 수 있습니다.
6. **구성(Configure) → 조회 주기 설정**에서 **자동 조절(권장)**을 켜 두면 등록된 전체 충전소 수에 맞춰 주기가 자동 조절되며, 원하면 수동 고정 주기(1~60분)로 전환할 수 있습니다.

> [!TIP]
> **일일 트래픽(1,000건) 관리 및 충전소 개수별 권장 갱신 주기**  
> 통합 구성요소는 충전소 1곳당 1회 갱신 시 `getChargerInfo`를 1회 호출합니다. 자동 조절 기능이 켜져 있으면 일일 한도의 약 85% 이내(850건 이하)가 되도록 아래 기준에 맞춰 주기를 자동으로 조정합니다.
>
> | 등록 충전소 수 | 자동/권장 갱신 주기 | 일일 예상 호출량 |
> | :---: | :---: | :---: |
> | **1곳** | **2분** (수동 2~3분 권장) | 480 ~ 720건 |
> | **2곳** | **4분** | 약 720건 |
> | **3곳** | **6분** | 약 720건 |
> | **4~5곳** | **8~10분** | 576 ~ 900건 |
> | **6~10곳** | **15~20분** | 432 ~ 960건 |
>
> - 1,000건 이상이 필요한 경우 공공데이터포털에서 **운영계정** 전환을 신청하거나, 갱신 주기를 길게 두고 필요 시에만 HA 자동화(`homeassistant.update_entity`)로 갱신할 수 있습니다.

## 4단계: 자동화 블루프린트 (구역별 충전 가능 대수 알림)

사용자가 미리 설정한 구역(최대 3개)에 진입할 때, 각 구역에 매핑해 둔 1개 이상의 충전소 센서에서 현재 충전 가능 대수를 모바일 앱 알림으로 전송하는 블루프린트를 제공합니다.

- **블루프린트 경로**: `blueprints/automation/ev_charger_kr/zone_arrival_charger_notify.yaml`
- **가져오기 URL**:
  ```text
  https://github.com/helico717/ha-ev-charger-kr/blob/main/blueprints/automation/ev_charger_kr/zone_arrival_charger_notify.yaml
  ```
- **Home Assistant에서 등록**: **설정 → 자동화 및 장면 → 블루프린트 → 블루프린트 가져오기**에 위 URL을 붙여넣고 아래 항목을 설정합니다.
  - **추적할 사용자 (`person`)** & **알림을 받을 모바일 기기 (`mobile_app`)**
  - **구역 1~3 설정**: 각 구역(`zone`)과 해당 구역 도착 시 확인할 **충전 가능 대수 센서(1개 이상)**
  - **알림 제목** (기본값: `⚡ 사용가능한 충전기 알림`, 사용자 수정 가능)
  - **알림 전 최신 상태 즉시 갱신** / **충전 가능 대수가 1대 이상일 때만 알림** 옵션
- **테스트 실행**: 자동화 화면에서 **`⋮ → 실행`**을 누르면 설정된 모든 구역의 현재 상태를 즉시 모바일 테스트 알림으로 받아볼 수 있습니다.
- **알림 예시**:
  ```text
  ⚡ 사용가능한 충전기 알림
  ▫️ 1대 가능 — 채비 (완속)
  ▫️ 6대 가능 — 이지차저 (완속)
  ```
